## 2026-11-25 주 모델과 대체 모델

사용자가 정했다("주 모델을 claude sonnet5.5로 해라. anthropic api는 fallback이야", 넘어가는 때는 한도·잔액·연결 문제).
사용자 PC에서 Anthropic API 잔액 부족으로 모델 점검이 실패한 뒤 나온 결정이다.

| 결정 | 답 |
| --- | --- |
| 화면 기본값 | 주 모델 `claude-code/claude-sonnet-5-5`(Aside에 Claude 계정으로 연결한 모델), 대체 모델 `anthropic/claude-sonnet-5-5`(Anthropic API). 설정 파일에 키가 없을 때만 쓴다. 추론 강도와 명령줄은 여전히 기본값이 없다 |
| 넘어가는 때 | 공급자가 사용량 한도, 잔액(크레딧) 부족, 연결·인증 문제로 거절해 모델이 끝 답을 내지 못한 세션. 모델 이름 오타 같은 다른 오류에는 넘어가지 않는다 |
| 하는 일 | 그 세션을 남은 시간 안에서 대체 모델로 한 번 다시 돌린다. 같은 실행의 다음 세션은 처음부터 대체 모델로 돈다. 저장된 설정은 바꾸지 않아 다음 조사는 다시 주 모델부터 돈다 |
| 끄기 | 화면의 `주 모델을 못 쓸 때 쓸 모델`을 비워 저장한다(키를 빈 값으로 남겨 기본값으로 되돌아가지 않는다) |
| 기록 | `run.model_fallback`(from, to, reason, message), 세션마다 `run.sessions.<역할>.model`·`fallback_from`, 결과 주의 칸 한 줄. 모델 확인(`model_verification`)은 그 세션에 요청한 모델과 비교한다 |
| 대체 모델도 거절 | 더 바꾸지 않고 그 실패로 끝낸다(잔액 부족이면 `research_unavailable:out_of_credit`) |

이 결정으로 2026-11-15의 "모델 기본값 없음"은 화면에서만 바뀐다. 아래 "빠진 것"의 모델 단계 전환은 그대로 빠져 있다.

## 사람 확인 화면 결정의 영향

- 조사 세션 지시 앞에 늘 붙는 공통 지시: 공개 원문 열람을 위한 사람 확인 체크박스·확인 버튼만, 컨트롤마다 한 번 누른다.
  로그인·회원가입·결제·폼 제출은 하지 않는다(`prompts.HUMAN_VERIFICATION_RULES`).
- 근거 다시 열기: 확인 화면 구조 표지가 보이면 최대 45초 기다리며 체크박스를 한 번 누른다(`aside/capture.py`).
- 누른 뒤에도 남으면 차단으로 기록하고 멈춘다. 차단 뒤 다른 방법(내려받기 이벤트, 뷰어 우회, 쿠키를 실은 받기)으로 다시 받지 않는다.
- 위생 검사(`tests/test_hygiene.py`)는 이 낱말이 정해 둔 파일에만 있는지 본다.
- Aside 약관 7절(접근 통제와 보안 조치 우회 금지)과 Aside 공식 문서(CAPTCHA는 사용자가 직접 끝낸다)에 닿는다. 공개 배포 전에 다시 정한다.

## 원래 코드에서 바꾼 것

원래 운영 코드의 학술대회 조사 판정을 옮겨 새로 썼다. 원래 코드 파일은 가져오지 않았다.

| 곳 | 바꾼 것 |
| --- | --- |
| 입력 | 논문명·학술대회명·저자명·연도 네 가지. 한글이 든 제목은 한글 제목 칸, 아니면 영문 제목 칸 |
| 연도 | 날짜 앞 4자 대신 글 속 4자리 연도 하나를 읽는다 |
| 항목 | 19개에서 13개 |
| 정책 이름 | `cpf-reconcile-v1`(대조 결정), `cpf-string-agreement-v1`(대조 답이 없을 때) |
| 결과 파일 | 모르는 최상위 키·지시하지 않은 항목·틀린 탐색 기록은 버리고 기록한다. 근거의 observation·locator는 비어도 받는다(2026-11-15 측정에서 빈 메모 한 칸으로 결과 전체가 버려졌다). 입력 결속과 나머지 관찰 꼴은 그대로 엄격하다 |
