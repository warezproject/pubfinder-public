# 채택 규칙

판정은 `src/pubfinder/verdict.py`가 한다. 두 조사 보고, 근거 다시 열기 요약, 대조 결정을 묶은 `bundle` 하나만 본다.
같은 bundle이면 언제 다시 계산해도 같은 판정이 나온다.

## 대조 정책 `cpf-reconcile-v1`

대조 세션이 형식에 맞는 답을 냈을 때 쓴다. 채택값은 1차 조사 값이다.

| 항목 | 채택 조건 |
| --- | --- |
| 모든 항목 | 1차 결론이 not_found가 아님, 두 조사 모두 값 있음, 대조 결정 agree |
| 논문 6개 | 위 조건과 같은 논문 합의(대조 identity agree, 두 조사 모두 same_paper) |
| 개최국, 국내·국제 구분 | 위 조건과 두 조사의 행사연도가 입력 연도와 같음, 역할 표지가 있는 직접 인용이 두 조사 모두 다시 연 원문에서 확인됨 |
| 나머지 항목 | 인용 확인은 `quote_verified`로 기록만 한다 |

같은 논문 합의가 없어도 행사 항목(행사명, 기간, 주관, 장소, 개최국, 구분)은 채택할 수 있다.
핵심 확인(`core_verified`)은 같은 논문 합의, 발표일 채택, 제목(한글 또는 영문) 채택이다.

## 문자열 일치 정책 `cpf-string-agreement-v1`

대조 답을 못 얻었을 때(실패, 시간 부족, 형식 오류) 쓴다.

| 조건 | 내용 |
| --- | --- |
| 항목 | 두 조사 모두 confirmed이고 공식 원문 근거가 있음, 정규화한 값이 같음, 인용 하나 이상이 다시 연 원문에서 확인됨 |
| 비교 예외 | 행사명 앞 The와 반복된 행사연도, 세션 끝의 논문 번호 설명 |
| 개최국 | 국가 코드가 같으면 표기가 달라도 같은 나라 |
| 핵심 | 두 조사 모두 같은 논문·행사연도 확인, 행사연도가 입력 연도와 같음, 발표일과 제목 채택, 발표일이 행사 기간 안 |

핵심이 확인되지 않거나 1차 결론이 found가 아니면 아무것도 채택하지 않는다. 연도가 없으면 이 정책에서는 채택이 없다.

## 개최국과 국내·국제 구분의 직접 근거

| scope | 근거 조건 |
| --- | --- |
| single_host_country | 인용에 국가명이 개최 표지(held in, venue, 개최 등) 뒤나 장소 표기 끝에 있음. 주최·후원 기관 주소는 근거가 아님 |
| location_inferred | 국가명 없는 개최 장소 인용으로 판단한 나라. 국가 코드 필요 |
| domestic_address | 국가명 없는 한글 장소 인용으로 판단한 한국(KR). 설정 `korean_place_as_korea`가 켜져 있을 때만 |
| online_only 등 | 온라인 전용, 복수국, 미정은 채택하지 않음 |
| classification_stated | 원문이 국내·국제 성격을 직접 밝힌 문장(12자 이상) |
| classification_inferred | 행사 소개·논문 모집처럼 성격을 판단할 수 있는 원문 문장(12자 이상) |

근거의 도구 값은 `aside_native_browser`, 근거 범위는 공식 행사 안내나 공식 프로그램이어야 한다.

## 인용 확인

인용을 생략 기호(… 또는 ...)로 나눈 조각마다 숫자·영문·한글만 남겨 다시 연 원문에서 찾는다.
조각은 8자 이상, 가장 긴 조각은 12자 이상이어야 한다. 원문은 화면 글과 HTML(또는 PDF 글)을 함께 본다.

## 미채택 사유

| 사유 | 뜻 |
| --- | --- |
| outcome_not_found | 1차 조사가 논문을 찾지 못함 |
| one_sided | 한쪽 조사만 값을 냄 |
| unconfirmed | 두 조사 모두 확인하지 못함 |
| reconcile_disagree, reconcile_primary_only, reconcile_review_only, reconcile_neither | 대조 결정이 agree가 아님 |
| identity_not_agreed | 같은 논문 합의가 없음 |
| event_year_unconfirmed | 행사연도가 입력 연도와 같다는 확인이 없음 |
| capture_unverified | 인용이 다시 연 원문에서 확인되지 않음 |
| values_differ | 문자열 일치 정책에서 두 값이 다름 |
| core_not_verified | 문자열 일치 정책에서 핵심이 확인되지 않음 |
| country_*, classification_* | 개최국·구분의 직접 근거 문제 |
| korean_place_rule_off | 한글 장소 규칙이 꺼진 상태의 domestic_address 보고 |

## 차단

근거 다시 열기에서 사람 확인 화면이 체크박스를 누른 뒤에도 남거나, 401·403·429를 받거나, 짧은 차단 문구 화면이 오면
그 주소는 `blocked`로 기록하고 더 시도하지 않는다. 차단된 근거의 인용은 확인되지 않은 것으로 센다.
