## 정답과 맞춰 본 것

표본을 고를 때 본 공개 일정표(학회 일정표, 참가 기업의 발표 일정 안내, PDF 일정표)의 값과 비교했다.

- 정답을 아는 발표일 10건이 채택돼 모두 같다. 1건(ICLR)은 한쪽 조사만 찾아 채택되지 않았다.
- 채택된 개최국 15건이 모두 실제 개최국과 같다(한국 8건 포함).
- 정답을 아는 세션 7건이 같다.
- 정답을 아는 발표 시각 6건이 같다. 1건(ICML 구두·포스터 겸 발표)은 구두 시각 대신 같은 날 포스터 시각이 채택됐다. 두 조사가 서로 다른 발표를 보고 세션은 엇갈렸고(reconcile_disagree), 시각은 둘 다 포스터 시각이었다.
- 공개 정보와 어긋난 채택값은 찾지 못했다. 나머지 채택값은 하나하나 대조하지 않았다.
